# IDE CPP -> Componentes

uma IDE parecida com o delphi/lazarus para C++

fluxo:
abrir a IDE -> inicar projeto/continuar existente/iniciar arquivo/abrir arquivo.cpp
area de codigo e area de componentes

# funcionamento dos componentes ->
clica e arasta pra onde quer (assim que o componente for colocado no formulario, automaticamente ja vai ser criado para ele uma funcao para modificarmos a logica dele)
exatamente como acontece no lazarus


estilo -> 2 libs pre instaladas de C++ com opção de instalar mais

# PROPOSITO

substituto ao Arduino IDE (com opção "criar projeto arduino" (futuramente vamos adicionar um pluguin para instalar libs a))
IDE para desenvolvimento avançado
se possivel, colocar intelissence principalmente para incemtivar o usuarios a escrever codigo otimizado como especialista (para ja pegar essas pratica e escrever codigo bom logo de começo)

area de testes de codigo que verifica tipos, tamanhos, limites e erros ( entre outras coisas )
