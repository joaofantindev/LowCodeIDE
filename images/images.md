Assets generated as a cohesive cartoon mascot/theme concept. The pack contains:
- Monkey mascot app icon and laptop mascot
- Light/dark application and editor backgrounds
- Folder/file illustrations
- Common UI icons (run, stop, debug, settings, terminal, plugins, bug, theme)
- C++ logo

These are raster PNGs, intended as visual prototypes. Some crops retain a little of the original dark preview background; use them as-is for mockups or remove backgrounds if you want to adapt them to transparent UI assets.

Suggested names for application usage:
- `icon_monkey.png`: app/window icon
- `background_light.png`, `background_dark.png`: landing/home backgrounds
- `editor_background_light.png`, `editor_background_dark.png`: canvas/editor backgrounds
- `folders_*.png`, `file_*.png`: file explorer decorations
